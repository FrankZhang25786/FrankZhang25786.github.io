Machine Vision · 小组项目

PythonYOLOv8 / UltralyticsSmall Object DetectionIoU / NMS

针对真实果园中的小目标、遮挡与密集分布，以 YOLOv8 检测器为核心，与团队的树区域提取、重叠切片和跨切片去重模块串联，比较完整流程与直接检测基线；再用另一果园数据集检验迁移效果。

个人贡献

主要负责 YOLOv8 苹果检测与计数模块及结果评估与分析；与负责树检测、滑动窗口和 NMS 的组员完成模块对接。

  • 转换原始 bounding-box 标注为 YOLO 格式，组织训练、验证与测试数据。
  • 训练单类别苹果检测器，使用独立测试数据进行推理与结果分析。
  • 对接 320 × 320 像素重叠切片、原图坐标恢复及跨切片去重流程。
  • 比较基线与完整方案，分析误检、漏检及跨数据集表现。

03

迷宫导航：固定环境与未见地图的泛化差距

Artificial Intelligence for Robotics · 课程实践 · 仿真验证

TensorFlow / Kerasscikit-learnQ-learning / SARSA

以虚拟迷宫机器人 HeroBot 为对象，实施图像分类、传感器聚类与表格型强化学习导航。在同一张地图上学得的导航策略表现良好，但换到未见地图后成功率急剧下降；通过训练和测试场景分离，识别状态表示的泛化限制。

100%固定 8 × 8 迷宫，Q-learning 与 SARSA
12% / 10%50 个未见随机迷宫，分别对应两种算法

结论：基于绝对位置与朝向的表格状态不能直接泛化到新地图；后续可探索局部观测或地图特征作为状态输入。后者为改进方向，非本项目已验证结果。

04

3Pi+ 双机器人跟随：遮挡下的状态预测

Pololu 3Pi+ · 三人团队课程项目 · 实机验证

差速机器人PD / PID扩展卡尔曼滤波轮式里程计

让跟随机器人依据红外信号调整距离与方向，并在短时遮挡、信号异常和地面纹理干扰下保持平稳响应。项目将传感器标定、闭环控制与状态估计结合，在两台实体机器人上开展对比实验。

项目参与

参与实机跟随系统开发、数据采集与实验分析。报告和图中方法为三人团队成果；对照曲线用于解释遮挡处理，不代表未测量的性能提升百分比。

从感知到控制

  • 测试红外传感器响应与有效范围，完成距离和方位标定。
  • 结合差速运动学，将外环 PD 跟随指令转换为左右轮目标速度，由轮速 PID 内环执行。
  • 结合红外观测与轮式里程计进行状态估计，降低原始测量噪声对控制输出的影响。

处理观测失效

  • 利用观测残差门控剔除不符合运动连续性的距离突变。
  • 遮挡时切换为自运动补偿预测，避免错误估计目标远离而继续加速。
  • 短时信号丢失时平缓减速；持续失联 1 秒触发停车。

实机对比结果

实验场景关注问题报告中的观察
稳态与动态跟随红外测量波动状态估计平滑测量噪声
短时遮挡信号丢失后的运动连续性由骤停转为平缓减速
地面纹理干扰异常观测引起的转向振荡剔除异常值后振荡减小

基于实机响应曲线进行定性对比，重点考察运动连续性与抗干扰表现。

控制结构、数据记录与适用边界
  1. 红外标定
  2. 观测有效性判断
  3. 状态更新或预测
  4. 外环跟随控制
  5. 轮速闭环执行

实验记录

以 20 Hz 在车载内存缓存 5 秒实验数据，试验后通过串口导出，比较观测、状态估计与电机响应，减少实时通信对控制的影响。

工程取舍

观测失效时采用保守预测以降低误加速风险。持续遮挡下无法可靠恢复领航机器人的真实运动，因此以超时停车限制预测误差，而非无限延长盲跟随。

机械臂示教学习与轨迹控制仿真

Robot Learning for Control · 课程项目 · MATLAB / Simulink

DMPGMM / GMR逆运动学SimscapePID + 前馈

从多条示教轨迹学习运动模式，将生成的二维轨迹映射为二自由度机械臂关节运动，并在仿真中研究运动学复现与力矩控制下的跟踪表现。

实现内容

使用 MATLAB 实现 DMP 与 GMM/GMR 轨迹学习、解析逆运动学，并在 Simulink/Simscape 中搭建机械臂仿真与 PID 加简化惯性前馈控制流程。

学习方法、控制实现与结果分析

学习与运动学映射

比较加权局部回归与 GMM/GMR 对示教轨迹的建模效果，将 DMP 生成轨迹通过二自由度机械臂解析逆运动学转换为关节参考，验证运动学层面的轨迹复现。

动力学控制分析

搭建 PID 与简化惯性前馈力矩控制。动力学仿真中仍存在跟踪滞后和轨迹变形，据此分析惯性近似及关节耦合未充分建模对跟踪的影响。
